# DisasterSim

DisasterSimは、架空の街で雨の強さと現在地を変え、浸水リスクを考慮すると避難先や経路がどう変わるかを試せるWebアプリです。同じ避難所までの最短経路と推奨経路を地図に重ね、何マス遠回りすると、経路上のリスクがどれだけ変わるかを比較できます。

**架空データを使う技術デモです。実際の避難判断には使用できません。**

## デモの見どころ

1. サイドバーで現在地を「商店街」、大雨の強さを「4」にします。
2. 地図で「西の学校」までの2本の線を比べます。距離だけで選ぶと10マスで、経路上の最大リスクは約59%です。危険度を考慮した青い経路は12マスで、最大リスクは約40%に下がります。
3. 雨の強さを「1」に戻すと、推奨先が「東の高台避難所」に変わります。Nosanaを設定していれば「選定理由をAIで説明」から、距離と危険度の関係を日本語で確認できます。

## 数値の読み方

街は15×15マスです。各マスに、川や低地との位置関係と雨の強さから求めた仮想リスクを設定しています。画面の百分率はこの指標の大きさを表し、実際の浸水確率を示すものではありません。

| 表示項目 | 意味 |
| --- | --- |
| 移動ステップ | 上下左右に隣のマスへ移る回数。4 stepsは4マス分の移動です。実距離や所要時間への換算はありません。 |
| 平均リスク／最大リスク | 出発地と到着地を含む、経路が通る全マスの仮想リスクの平均値／最大値です。 |
| 評価対象の避難先 | 候補3か所のうち、モデル上で経路が見つかった避難所の数です。 |
| 推奨避難所 | 1歩ごとに「1 + 9 × 移動先マスのリスク²」を足し、合計が最小になる経路の行き先です。リスクは0〜1の値を使います。 |

## 技術構成

- **Streamlit / Plotly** が現在地と雨量の入力を受け取り、仮想リスクの地図、経路、避難所ごとの指標を表示します。
- **Python / Daytona** が経路計算を担います。通常はローカルで実行し、「Daytona上で経路計算」を有効にすると、同じPythonコードをDaytonaのサンドボックスで実行します。
- **Nosana / Ollama** は計算結果の解説を担います。チームの構成はNosana GPU（RTX 3090）上でOllamaを動かし、オープンな言語モデルを提供するものです。アプリはデプロイのOpenAI互換API（`NOSANA_URL/v1`）に接続し、提供中のモデルに距離・リスク・推奨先を渡します。解説には架空データである旨を含めるよう指示しています。

## 起動方法

Python 3.11以上を用意し、展開したフォルダの `app.py` と同じ階層で実行してください。ローカルで地図と経路を試すだけなら、APIキーは不要です。

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

**Windows PowerShell**

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

クラウド連携を使う場合は、起動前に同じターミナルで利用するサービスの環境変数を設定します。以下はPowerShellの例です。

```powershell
$env:NOSANA_URL="your_nosana_deployment_endpoint_url"
$env:DAYTONA_API_KEY="your_daytona_api_key"
```

macOS / Linuxでは `export NOSANA_URL="your_nosana_deployment_endpoint_url"` の形式で設定します。Ollama用のURLは末尾の `/v1` を除いて指定してください。モデルは提供一覧の先頭を使い、必要に応じて `NOSANA_MODEL` で指定できます。Nosanaのホスト型推論を使う場合は `NOSANA_URL` を未設定にし、`NOSANA_API_KEY` を設定します。

## 実装範囲と今後の構想

現在の入力は、雨の強さとあらかじめ用意した3つの出発地点です。次に目指すのは、「駅前の道が冠水している」のような観察を入力すると、AIが場所・危険度・情報の不確かさを読み取り、地図と経路が更新される体験です。文章や地図への手書きから危険区域を更新する機能は今後の開発対象です。

## Judging honesty

発表でDaytona連携を示す際は、計算元に「Daytona sandboxで実行」と表示されたことを確認します。ローカルへの切り替えが起きた場合は、その旨が画面に表示されます。Nosana連携は「選定理由をAIで説明」で実際に解説が返ったことを確認して紹介します。実際のハザードマップ、道路の通行規制、避難所の開設状況は扱っていません。
